# T34 — Read Aloud with Word Highlighting: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Speak a PDF from the reader's place in reading order, highlight each spoken word on the page, and offer paragraph/chapter navigation, speed, voice choice and a sleep timer, all offline.

**Architecture:** The engine turns a page into spoken paragraphs whose words carry the page rectangles for highlighting. An app-side synchronous controller turns playback into actions (`Speak`, `Highlight`, `ScrollTo`, `NeedPage`, …) so the same logic can later run inside T64's service. The viewer executes those actions: TTS speaks, the page overlay paints the word, the list scrolls.

**Tech Stack:** Kotlin, Jetpack Compose, Android `TextToSpeech` (API 26+, `onRangeStart`), engine `ReflowExtractor` (T33) and `PageLayout.rectsFor` (T11), JUnit4 unit tests, Compose UI tests.

**Spec:** `docs/superpowers/specs/2026-10-30-t34-read-aloud.md`

## Global Constraints

- `:engine` is pure Kotlin/JVM: no `android.*`, no new dependency. `:app` adds **no dependency** in this task.
- Nothing is written into the PDF; read aloud is view state plus `AppSettings`/`ReadingState` app data.
- Offline voices only: a voice with `isNetworkConnectionRequired == true` is never used or listed.
- Positively: the UI says TTS uses CPU and battery and that no data leaves the device.
- Every engine change runs `./gradlew :engine:test`; every app change runs `./gradlew :app:testDebugUnitTest`; the task is done only when `./gradlew build` is green.
- Do not weaken or delete an existing test. Existing T11/T33/T56/T61 tests must stay green.
- Stage only the files each task lists when committing (the working tree has unrelated uncommitted work from T46–T63).
- Cite ISO 32000-1 sections in engine comments: outline §12.3.3, destinations §12.3.2.
- Windows: `$env:JAVA_HOME="C:\Users\hp\tools\jdk-17.0.20.1+1"`, run `.\gradlew.bat` from the repo root.

## Review Focus

- **A page with no text layer** (a scan): the reader must hear an explanation and playback must move on, not fall silent or loop.
- **A TTS engine that never reports `onRangeStart`**: the word highlight must degrade to the paragraph with a visible message, not stay blank forever.
- **A hyphenated word across a line break**: it must be spoken once and highlighted on both lines.
- **An outline entry whose destination page no longer exists** (a file saved by another tool): the chapter must be skipped, not crash `next chapter`.
- **A stored voice that the device no longer has**: playback must fall back to the default voice and say so, never fail silently.

- [ ] **Step 3: Implement the models and extractor**

`extract` runs `ReflowExtractor.extract(page, options.reflow, decoder)`; returns its failure as `Result.failure`. For each text block (PARAGRAPH/HEADING/LIST_ITEM), take the block's `pageTextStart until pageTextEnd` from `layout.text`, split into tokens on whitespace, and build words:
- a token ending in `-` whose next token's rect top differs by more than 0.5 pt joins it into one word (rects from both, text without the hyphen);
- word offsets are computed as the final spoken string is assembled (one space between words);
- rects come from `layout.rectsFor(tokenStart, tokenEnd)`; join the rects of a hyphen pair;
- `fraction` from the block bounds' centre through `PageGeometry.matrixFor(box, 1.0, 1.0)`, clamped 0..1;
- `headingLevel` from `block.level`; `headings` collects level 1–2 heading blocks with their paragraph index;
- blocks with no word are dropped; picture/table blocks produce nothing.

`isBlank()` on `SpeechPage.paragraphs` is what the app uses to report a page with no text.

- [ ] **Step 3: Implement the controller**

Rules the tests pin:
- `start`/`resume` ask `feed.page(position.pageIndex)`; when it is null the actions end with `NeedPage(pageIndex)` and the controller remembers the pending start. `onPageReady` continues.
- The current paragraph is spoken with `utteranceId = "p:<page>:<paragraph>"`; its text is `paragraph.text`.
- `onWordStart` finds `paragraph.wordAt(start)`; emits `Highlight(page, paragraph, word.rects, false)`; when no word matches, `Highlight(…, listOf(paragraph.bounds), true)` and once sets `hasWordRanges = false` with a message. `onUtteranceDone` clears the highlight and advances.
- Sleep: `MINUTES_*` uses `SleepTimer(option, clock())`; `tick` pauses with `SLEEP` when expired. `END_OF_CHAPTER` pauses before speaking a paragraph that starts a different chapter (or a page past the chapter's page), and when no chapter list exists it behaves like `OFF` with a one-time message.
- `nextChapter`: no chapter list or none after → `Finished`. `previousChapter`: if the position is past the current chapter's first paragraph, go to that first paragraph; else the previous chapter.
- A page with `paragraphs.isEmpty()` emits `Paused(NO_TEXT, "No text on this page")` and remembers it was a skip; `resume()` then proceeds to the next page (never loops on the same page).
